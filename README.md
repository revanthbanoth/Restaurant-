# Spice Garden - Premium Indian Restaurant Website

A complete, beautiful, and fully responsive single-page restaurant website built entirely within a single HTML file. This project is crafted to provide a premium user experience with modern aesthetics, smooth animations, and perfect layout rendering across all device sizes.

## 🌟 Features

- **Single File Architecture**: All HTML, CSS, and JavaScript are bundled into a single, high-performance `index.html` file without relying on heavy external JavaScript frameworks.
- **Fully Responsive Layout**: Built with CSS Grid and Flexbox, ensuring zero horizontal scroll. Every section seamlessly adapts from small mobile devices to large desktop monitors.
- **Fluid Typography**: Utilizes CSS `clamp()` to dynamically scale font sizes depending on the viewport width.
- **Premium Design System**:
  - Custom color palette: Golden primary (#c8a951), Warm Orange accent (#e85d04), and Near-Black backgrounds.
  - Elegant typography featuring **Playfair Display** for headings and **Poppins** for clean body text.
- **Interactive UI Components**:
  - **Dynamic Navbar**: Features a backdrop-blur scroll effect and a smooth slide-in mobile hamburger menu.
  - **Hero Section**: Includes a deep spice-colored gradient, floating particle animations, and a subtle grain overlay.
  - **Floating Stats**: Animated, JS-powered count-up statistics that trigger on scroll.
  - **Interactive Menu**: Functional category filtering tabs using Vanilla JS with smooth fade transitions.
  - **Testimonials Carousel**: A responsive grid that automatically turns into a smooth-scrolling carousel on mobile devices.
  - **Reservation System**: A styled, robust reservation form integrated alongside structured contact details.
- **Scroll Animations**: Sections smoothly fade and slide into view utilizing the `IntersectionObserver` API.

## 🛠️ Technologies Used

- **HTML5**: Semantic and accessible markup.
- **Vanilla CSS3**: Advanced layouts, variables, gradients, and keyframe animations.
- **Vanilla JavaScript (ES6)**: DOM manipulation, event handling, counting animations, menu filtering, and mobile carousels.
- **Google Fonts**: Custom typography integration.
- **Font Awesome**: Lightweight, scalable vector icons.

## 🚀 How to Run

Because the entire application is contained within a single file and uses no backend or build steps, running it is incredibly simple:

1. Locate the `index.html` file in your directory.
2. Double-click the file to open it directly in your default web browser (Chrome, Firefox, Safari, Edge, etc.).
3. *(Optional)* If you use an IDE like VS Code, you can also use an extension like **Live Server** to run it with hot-reloading for further development.
